# 🔥 Encuesta: Uso de gas en la cocina y detector de gas

Encuesta web (HTML) para un proyecto sobre seguridad del gas en el hogar.
Mide los hábitos de cocina y la intención de uso de un **detector de gas**.

## 📋 Preguntas (todas de opción múltiple)

1. ¿Cada cuánto cocinas en tu casa?
2. ¿Cuántas veces prendes la estufa al día?
3. ¿Cómo te aseguras de que no hay fuga de gas al cambiar el tanque?
4. ¿Cada cuánto cambias o recargas el tanque de gas?
5. ¿Usas gas en otro lugar además de la cocina?
6. ¿Usarías un detector de gas en tu casa?

## 📊 Resultados

La página calcula automáticamente **promedios y porcentajes** de cada
pregunta, con barras de resultados, al momento de guardar cada respuesta.

- Los datos se guardan en el navegador (localStorage) del dispositivo.
- Botón para **exportar CSV** y analizar todo en Excel o Google Sheets.

## 🚀 Cómo verla

Abre el enlace de GitHub Pages de este repositorio (Settings → Pages)
o descarga `index.html` y ábrelo con doble clic en cualquier navegador.
No necesita internet ni instalar nada.
